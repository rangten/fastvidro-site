# ⚡ Fast Vidro — Plataforma Comercial de Alta Performance & SEO Programático

A **Fast Vidro** é uma plataforma web voltada para o mercado de vidraçaria premium e soluções residenciais (Box de Banheiro, Portas de Vidro e Espelhos) na Grande São Paulo. Desenvolvido do zero via Lovable, o projeto foi arquitetado com foco extremo em conversão de leads (CRO) e otimização avançada para motores de busca (SEO), possuindo mais de 155 páginas indexadas e ranqueadas organicamente em tempo recorde.

🔗 **Acesse a aplicação oficial:** [fastvidro.com.br](https://www.fastvidro.com.br)

---

## 🚀 Destaques do Case de Sucesso

* **Geração Real de Leads:** O sistema atua como o principal motor comercial de uma operação ativa, capturando e direcionando intenções de compra diretamente para canais de atendimento integrados.
* **SEO Avançado e Indexação Escalável:** Estrutura de rotas e metadados otimizada que garantiu a indexação automatizada de mais de 155 páginas no Google (focadas em geolocalização e variações de produtos como Box Incolor 8mm, Espelhos Decorativos e a tecnologia exclusiva *Secure Box*).
* **Segmentação Geográfica Inteligente:** Módulo dinâmico de atendimento mapeado para mais de 70 bairros divididos por zonas (Norte, Sul, Oeste, Leste e Centro de São Paulo), maximizando a relevância em buscas locais.
* **Design Focado em Valor (CRO):** Identidade visual moderna em alto contraste (Premium Dark/Gold), posicionamento estratégico de CTAs e apresentação de pilares de autoridade (Segurança, Agilidade, Qualidade e Tradição).

---

## 💻 Stack Técnica

* **Frontend:** React.js de última geração integrado com TypeScript.
* **Estilização & Componentes:** Tailwind CSS para layouts responsivos ultra velozes e shadcn-ui para interações polidas.
* **Infraestrutura de SEO:** Otimização de performance de carregamento, estruturação de tags semânticas (H1-H6), geração de Sitemap dinâmico e arquitetura focada em Core Web Vitals para favorecer o algoritmo do Google.
* **Desenvolvimento:** Engenharia ágil com Lovable, aliando velocidade de deploy à customização fina de código para produção.

---

## 💼 Visão de Engenharia de Crescimento (Growth)

Este projeto vai muito além do desenvolvimento front-end tradicional. Ele demonstra a capacidade de alinhar código limpo à estratégia de negócios real. A rápida indexação e a performance de conversão validam o uso de plataformas de desenvolvimento guiadas por IA para construir sistemas robustos de aquisição de clientes, reduzindo drasticamente o CAC (Custo de Aquisição de Clientes) através de tráfego orgânico qualificado.
